# Необходимо создать функцию создания папок!
Необходимо: 
1. Cоздавать папки и подпапки
2. Возможность перемещать уже добавленные проекты в папки или под папки
3. Отображение папок в главном окне с возможностью перехода в них и просмотра проектов в них
4. Сворачивание папок и под папок в боковом меню

Пример:
------------------------------------------------------------
| Древо проектов         |      Главное окно               |
| Папка 1                |          Папки                  |
| - Подпапка 1           |   ----------   ----------       |
| - Проект 1             |  / Папка 1 |  / Папка 2 |       |
|  - Подпапка подпапки 1 |  |----------  |----------       |
| Папка 2                |                                 |
| - Проект 2             |          Проекты                |
|------------------------|   ------------  -----------     |
| Проекты не в папках    |   | Проект 1 |  | Проект 2|     |
| Проект 3               |   ------------  -----------     |
| Проект4                |                                 |
------------------------------------------------------------

За референс береём Altium 365
