# Система Папок для Организации Проектов

## Обзор

Реализована система папок для организации проектов в KiCAD Prism, вдохновленная функциональностью Altium 365. Эта функция позволяет пользователям группировать проекты в папки и подпапки для лучшей организации рабочего пространства.

---

## Возможности

### ✅ Реализованные функции

1. **Создание папок и подпапок**
   - Создание корневых папок (без родителя)
   - Создание вложенных подпапок (неограниченная глубина)
   - Диалоговое окно с выбором родительской папки

2. **Перемещение проектов**
   - Перемещение проектов между папками через контекстное меню
   - Перемещение проектов в корень (без папки)
   - Автоматическое удаление из предыдущей папки

3. **Отображение папок**
   - Древовидная структура в боковом меню
   - Счётчик проектов в каждой папке (включая подпапки)
   - Индикация текущей выбранной папки
   - Разворачивание/сворачивание папок

4. **Навигация**
   - Клик по папке → отображение проектов в ней
   - Кнопка "Back to All" для возврата ко всем проектам
   - Раздел "All Projects" в боковом меню

5. **Управление папками**
   - Переименование папок
   - Удаление папок (проекты перемещаются в родительскую или корень)
   - Контекстное меню для быстрых действий

## API Endpoints

### Папки

| Метод | Endpoint | Описание |
|-------|----------|----------|
| `GET` | `/api/folders/` | Получить все папки (плоский список) |
| `GET` | `/api/folders/tree` | Получить дерево папок |
| `GET` | `/api/folders/root` | Получить только корневые папки |
| `GET` | `/api/folders/{folder_id}` | Получить папку по ID |
| `GET` | `/api/folders/{folder_id}/children` | Получить дочерние папки |
| `GET` | `/api/folders/{folder_id}/projects` | Получить проекты в папке |
| `POST` | `/api/folders/` | Создать новую папку |
| `PUT` | `/api/folders/{folder_id}` | Обновить папку |
| `DELETE` | `/api/folders/{folder_id}` | Удалить папку |

### Проекты в папках

| Метод | Endpoint | Описание |
|-------|----------|----------|
| `POST` | `/api/folders/{folder_id}/projects/{project_id}` | Добавить проект в папку |
| `DELETE` | `/api/folders/{folder_id}/projects/{project_id}` | Удалить проект из папки |
| `POST` | `/api/folders/projects/{project_id}/move` | Переместить проект |

## Использование

### Создание папки

1. Нажмите кнопку `+` рядом с заголовком "Folders" в боковом меню
2. Введите имя папки
3. (Опционально) Выберите родительскую папку для создания подпапки
4. Нажмите "Create Folder"

### Перемещение проекта в папку

1. Найдите проект в списке
2. Нажмите на иконку `⋮` (три точки) на карточке проекта
3. Выберите целевую папку из меню
4. Проект будет перемещён

### Переименование папки

*Планируется:* Контекстное меню папки → "Rename"

### Удаление папки

*Планируется:* Контекстное меню папки → "Delete"
- Проекты будут перемещены в родительскую папку или корень
- Подпапки должны быть удалены сначала

## Безопасность

### Валидация

- Проверка на пустые имена
- Проверка на дубликаты имён в одной папке
- Предотвращение циклических ссылок (папка не может быть своим родителем)
- Проверка существования родительской папки

### Ограничения

- Минимальная длина имени: 2 символа
- Максимальная глубина вложенности: не ограничена
- projects могут быть только в одной папке одновременно

## Миграция Существующих Проектов

При обновлении существующей установки KiCAD Prism:

1. Все существующие проекты остаются без изменений
2. Поле `folder_id` по умолчанию `null` (проекты в корне)
3. Старые проекты автоматически отображаются в "All Projects"
4. Ручное перемещение в папки через UI

### Версия 1.6 (25 февраля 2026) - Подпапки и улучшения

**Исправлена критическая проблема:**

**Проблема:** При перемещении проекта в папку, проект не отображался в папке при открытии.

**Причина:** Функция `move_project_to_folder` обновляла только список `project_ids` в папке, но **не обновляла `folder_id` в registry проекта**. Поэтому frontend фильтровал проекты по старому значению `folder_id` (null).

**Решение:**
1. Добавлена функция `update_project_folder_id()` в `project_service.py`
2. Функция обновляет `folder_id` проекта в `.project_registry.json`
3. Очищается кэш проектов для немедленного обновления данных
4. `move_project_to_folder` теперь вызывает `update_project_folder_id`

**Изменённые файлы:**
- `backend/app/services/folder_service.py` — вызов `update_project_folder_id`
- `backend/app/services/project_service.py` — новая функция `update_project_folder_id`
