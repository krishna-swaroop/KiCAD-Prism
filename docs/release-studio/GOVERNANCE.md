# Release Studio governance (archived)

Policy evaluation, waivers, approvals, signed attestations, the Library tab,
web shares, and offline verify are **not** in the running Release Studio
product.

That work is frozen on `feature/release-studio-governance`. Restore or cherry-
pick from that branch if a later release needs a signed, policy-gated library
again.

The current product publishes a documentation zip to a GitHub or GitLab
Release. See the [user guide](USER_GUIDE.md).
