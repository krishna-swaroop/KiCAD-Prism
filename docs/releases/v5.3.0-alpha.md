# KiCAD Prism v5.3.0-alpha

This release adds Supply, which tracks distributor stock, prices and lifecycle
for your parts, and a switch to run Prism without it. It also reworks the
Visualizers page, lets schematic net highlighting follow a net across sheets,
and keeps review comments in place as a design changes.

**Back up before upgrading.** Follow the [upgrade runbook](https://krishna-swaroop.github.io/KiCAD-Prism/admin/upgrades/).

- **Schema:** catalog migrations 17 to 21 add Supply's tables and their links
  to library components. They run whether or not Supply is on.
- **Design bundles are rebuilt.** `prism-kicad` moves to 0.14.1, so every
  bundle is rebuilt on its own after the upgrade.
- **Desktop agent and KiCad plugin:** 0.5.18.
- **Settings:** `PRISM_SUPPLY_ENABLED` (default `true`), the `SUPPLY_*`
  settings, and `PRISM_GIT_CREDENTIALS`. A setting left empty in `.env` now
  takes its default, so an `.env` from an older release keeps working.

## Supply

Supply reads stock, prices, lead times and lifecycle from the distributor
accounts you connect, and stock from an InvenTree-compatible inventory server.
It shows them per part, per library component and per project, and warns about
parts that are ending, short or rising in price. See
[Track supply](https://krishna-swaroop.github.io/KiCAD-Prism/use/supply/) and
[Connect distributors and inventory](https://krishna-swaroop.github.io/KiCAD-Prism/admin/supply/).

- **Run without it:** set `PRISM_SUPPLY_ENABLED=false`. Prism then has no
  Supply pages, tabs or columns, no Supply API or MCP tools, and makes no
  distributor or inventory call. Release Studio takes no Supply snapshot and
  offers no compliance draft. The tables are still created, and stay empty.
- **Distributors:** DigiKey, Mouser, TME, Arrow and Farnell through their APIs;
  LCSC from an uploaded file; JLCPCB from an uploaded file or the jlcparts
  catalogue. Arrow, DigiKey and Farnell are built from their documentation and
  have not run against the live services yet.

## Visualizers

- **More room for the design.** In Visualizers the project sidebar is a column
  of icons that opens on hover, the header is thinner, and rarely used actions
  (Open in KiCad, Issue Tracker, Project Settings) are in a **⋯** menu.
- **The view stays put.** Opening the Selection or Comments panel no longer
  moves the design.
- **Nets across sheets.** Highlighting a net on the schematic marks it on every
  sheet. Tracing a global label, sheet pin or power symbol opens a world view
  of the sheets it reaches, joined by lines.
- **Sheets:** clicking a sheet selects it at its own size, and the inspector
  shows its name and file.
- **Measuring:** the PCB measure tool snaps to pads and vias anywhere on their
  copper, to track ends and to the board edge and its corners.
- The keyboard shortcuts dialog lists the net tracing shortcuts.

## Review comments

- An area comment stays where it was drawn while the sheet or board it was
  drawn on exists, even after that sheet is edited. Only a deleted or renamed
  sheet sends it to **Area needs review**.
- Comments over dialogs: comment cards no longer cover dialogs and prompts.

## Other changes

- **Git:** `PRISM_GIT_CREDENTIALS` gives HTTPS tokens for Git servers other than
  GitHub, each picked by URL prefix (#945).
- **Workflows:** a workflow job in a repository that holds several projects
  commits its outputs again (#985).
- **Desktop agent:** opening a project finds a checkout cloned by hand from its
  Git origin, instead of offering to clone it again (#500).
- **KiCad plugin:** a ticked checkbox no longer loses its label, the dialogs
  widen to fit their content, and a crash inside the plugin leaves a Python
  stack in `plugin-crash.log` beside the agent's settings (#1121).
- **Embedded viewer:** it no longer sends board files to an address given in
  the page URL, and the web app sends stricter security headers.
- **Nets:** a board that is behind its schematic no longer merges unrelated
  schematic nets under one stale board net (#1100).

## Known issues

- The SDK is not on PyPI yet; install it from the release's source tree.
- Where a sheet repeats a sheet-pin name, the `_N` numbers can be assigned in a
  different order from KiCad's. The nets themselves match.
- Simulation Studio is experimental.
