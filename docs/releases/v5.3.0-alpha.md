# KiCAD Prism v5.3.0-alpha

This release adds supply data to the Component Database: stock, price and
lifecycle of each component's parts from distributors and from your own
inventory, and whether a project can be built. A deployment that isn't ready
for it can switch it off. It also reworks the Visualizers page, follows a
schematic net across sheets, and keeps review comments in place as a design
changes.

**Back up before upgrading.** Follow the [upgrade runbook](https://krishna-swaroop.github.io/KiCAD-Prism/admin/upgrades/).

- **Schema:** five catalog migrations (steps 17 to 21) add the supply tables,
  a component's parts and alternates, inventory sources and their links to
  library components. They change no existing data, and run whether or not
  Supply is on.
- **Design bundles are rebuilt.** `prism-kicad` moves to 0.14.1, so every
  bundle is rebuilt on its own after the upgrade.
- **Desktop agent and KiCad plugin:** 0.5.18.
- **Settings:** `PRISM_SUPPLY_ENABLED` (on by default), `SUPPLY_HTTPS_PROXY`,
  `SUPPLY_OAUTH_BASE_URL`, `SUPPLY_INVENTORY_PRIVATE_HOSTS_STR`,
  `SUPPLY_ENABLE_SIMULATED_PROVIDER` (all off by default) and
  `PRISM_GIT_CREDENTIALS` are added. A setting left empty in `.env` now takes
  its default, so an `.env` from an older release keeps working (#964).
  Distributor credentials and inventory tokens are encrypted with
  `TRACKER_CREDENTIAL_ROOT_KEY`, so set it before you add a connector.
- **Dependencies:** the backend adds `openpyxl`, to read BOM files in Excel.

## Supply in the Component Database

Supply follows your library components; there is no separate parts database.
To run Prism without it, set `PRISM_SUPPLY_ENABLED=false`: Prism then has no
Supply pages, tabs or columns, no Supply API or MCP tools, and makes no
distributor or inventory call. Its tables are still created, and stay empty.
A part number no component has can be looked up once, but it is never tracked.

- **A component's Supply tab** shows its parts, your local stock and each
  distributor's stock, price and lifecycle, with the history.
- **Alternates.** A designer proposes another manufacturer part a component
  may be built with; it counts once QA approves it. Approved alternates add
  their stock and offers wherever the main part counts.
- **The catalog** has a **Supply** column and the filters **Tracked**,
  **At risk** and **In local stock**, and can track many components at once.
- **Ending parts.** The Supply Dashboard lists library components whose part
  is ending. QA marks them **Not for new designs**, retires them or dismisses
  the notice until something new happens.

## Can we build it

- **A project's Supply tab** answers how many boards the stock covers, what
  they cost, and which lines stop the build. Lines count approved
  alternates, and a line the library doesn't have says **Not in library**
  with **Add to Component Database**.
- **BOM columns** in the Visualizer show status, stock, price and lead time
  per line.
- **Release Studio** shows the supply health of the BOM a release ships and
  records it with the release. It never blocks a release.
- **Costing** downloads the costing per line and per distributor, a draft
  RoHS and REACH declaration and the trade classification.

## Distributors and inventory

- **Distributors:** TME, Mouser, DigiKey (with change notices), Farnell,
  Newark and element14, Avnet, Arrow, and file uploads for LCSC, JLCPCB and
  any CSV. Each connector has a daily call budget, and Prism spaces its reads
  to stay within it.
- **Local inventory:** Prism reads stock from any server with InvenTree's REST
  API, over HTTPS, including one on your own network once its host is listed in
  `SUPPLY_INVENTORY_PRIVATE_HOSTS_STR`. It matches each part to a library component by a person's
  link, the SAP code or the part number, and splits the stock into available,
  held and at a vendor. Parts it cannot match wait in **Supply → Review**.
- Connectors, inventory sources and Supply settings are in **Supply →
  Sources**.

## Supply over MCP

Five new tools: `get_project_supply`, `get_component_supply`,
`find_part_alternatives`, `watch_component` and `refresh_component_supply`.
Reads never call a distributor; the refresh tool makes one read within the
same per-person limit as the app. Approving alternates, waivers and
connectors stay with people.

## Visualizers

- **More room for the design.** In Visualizers the project sidebar is a column
  of icons that opens on hover, the header is thinner, and rarely used actions
  (Open in KiCad, Issue Tracker, Project Settings) are in a **⋯** menu.
- **The view stays put.** Opening the Selection or Comments panel no longer
  moves the design.
- **Nets across sheets.** Highlighting a net on the schematic marks it on every
  sheet. Tracing a global label, sheet pin or power symbol opens a world view
  of the sheets it reaches, joined by lines.
- **Sheets:** clicking a sheet selects it at its own size, and the inspector
  shows its name and file.
- **Measuring:** the PCB measure tool snaps to pads and vias anywhere on their
  copper, to track ends, and to the board edge and its corners.
- Comment cards no longer cover dialogs and prompts.

## Review comments

An area comment stays where it was drawn while the sheet or board it was drawn
on exists, even after that sheet is edited. Only a deleted or renamed sheet
sends it to **Area needs review**.

## Other changes

- **Git:** `PRISM_GIT_CREDENTIALS` gives HTTPS tokens for Git servers other than
  GitHub, each picked by URL prefix (#945).
- **Workflows:** a workflow job in a repository that holds several projects
  commits its outputs again (#985).
- **Desktop agent:** opening a project finds a checkout cloned by hand from its
  Git origin, instead of offering to clone it again (#500).
- **KiCad plugin:** a ticked checkbox keeps its label, the dialogs widen to fit
  their content, and a crash inside the plugin leaves a Python stack in
  `plugin-crash.log` beside the agent's settings (#1121).
- **Embedded viewer:** it no longer sends board files to an address given in
  the page URL, and the web app sends stricter security headers.
- **Nets:** a board that is behind its schematic no longer merges unrelated
  schematic nets under one stale board net (#1100).
