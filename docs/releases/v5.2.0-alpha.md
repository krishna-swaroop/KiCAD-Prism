# KiCAD Prism v5.2.0-alpha

This release lets an AI assistant take a new component through the catalog to
QA Review, and moves Prism's documentation to a website:
https://krishna-swaroop.github.io/KiCAD-Prism/.

**Back up before upgrading.** Follow the [upgrade runbook](https://krishna-swaroop.github.io/KiCAD-Prism/admin/upgrades/).

- **Schema:** no migrations.
- **No design bundles are rebuilt.** `prism-kicad` stays at 0.14.0.
- **Settings:** none are added. `PRISM_KICAD_PYTHON` may now be left unset;
  Prism then finds KiCad's Python beside `kicad-cli`. A value you set still
  wins.

## Catalog authoring over MCP

With `catalog:write`, an assistant can now create a component, fill in its
metadata, attach its files and take it to QA Review. Prism doesn't make the
files: the assistant brings them, and Prism checks and stores them. Approving
and releasing the part stay with a QA reviewer.

- **New tools:** `list_catalog_fields`, `search_catalog_assets`,
  `check_catalog_asset`, `update_catalog_component`, `create_asset_upload`,
  `attach_catalog_asset`, `reuse_catalog_asset`, `validate_catalog_component`,
  `update_catalog_representation`, `remove_catalog_representation`,
  `move_catalog_component` and `request_catalog_approval`.
- **Check before storing:** `check_catalog_asset` reports whether KiCad can read
  a draft symbol or footprint, its KLC findings and a picture of each unit,
  without saving anything.
- **Large files:** `create_asset_upload` returns a one-time URL to `PUT` a file
  such as a STEP model, up to 64 MiB, valid for 15 minutes. An attached 3D
  model is embedded in the footprint Prism serves.
- **Shared footprints:** `reuse_catalog_asset` gives a component an asset the
  catalog already stores, without copying it.
- **Stops at QA Review:** `move_catalog_component` moves a component only to
  In progress or QA Review. Moving it further needs `catalog:qa`, which only a
  person signed in to Prism holds; `request_catalog_approval` hands the step
  back as a link.
- **Guarded edits:** edits name the revision they change, so an assistant
  can't overwrite someone else's newer edit.
- A symbol that extends another, such as KiCad's LM358, now loads: the derived
  symbol is flattened when it is imported.

For contributors, each MCP tool is declared in one place with its group and
result shaping. `backend/app/services/mcp/AGENTS.md` and the `prism-mcp-tool`
skill describe how to add one, and tests check every tool's order,
annotations and documentation.

## Documentation website

The user and administrator guides are now a website, built from `website/` and
published to GitHub Pages from `main`. It has search, screenshots and short
clips of each workflow. The guides in `docs/` are replaced by short pages that
link to the website, so existing links keep working. The GitHub and GitLab
setup links in Prism's settings open the website.

## Other fixes

- Design bundles build on a Windows development host (#921).
- In Library Manager, a long symbol or footprint name no longer runs over the
  other fields of a representation row. It ends in an ellipsis, and the full
  name shows on hover.

## Known issues

- The SDK is not on PyPI yet; install it from the release's source tree.
- Where a sheet repeats a sheet-pin name, the `_N` numbers can be assigned in a
  different order from KiCad's. The nets themselves match.
- A board file with a missing parenthesis that KiCad tolerates, such as
  `(curved_edges no)filter_ratio 0.9)`, fails to parse.
- Simulation Studio is experimental.
