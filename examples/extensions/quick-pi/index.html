Model and limits

Fixed-temperature, constant-current DC screening. Traces use R = ρL/(wt); via barrels use R = ρL/[πp(d + p)], where d is the finished hole diameter. Identical parallel paths divide resistance by their count. Drop = IR; loss = I²R.

Geometry is entered manually, not extracted from this Prism project. No copper mesh, spreading/contact resistance, current crowding, unequal via sharing, AC, transient, thermal, fusing or current-capacity qualification is performed. A drop-budget result applies only to this declared path.
